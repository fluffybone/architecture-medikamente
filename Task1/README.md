# Задание 1. Анализ безопасности системы

## Выявите конфиденциальные данные, которые не учтены во внутренних системах.

Система обрабатывает:

1.  Персональные данные (ПДн): Ф.И.О., дата рождения, телефон, электронная почта, адрес, место работы/учёбы.

2.  Медицинская информация: Заболевания, диагнозы, результаты анализов, заключения специалистов, история обращений.

3.  Финансовая информация: Данные о платежах, оказанных услугах, контрактах.

## Создайте диаграммы потоков данных (Data Flow Diagrams). Для каждого процесса создайте отдельную диаграмму.

Основыне БП:

- Запись пациента на приём
- Проведение медицинского приёма
- Оплата услуг
- Бухгалтерский и складской учёт
