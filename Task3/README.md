# Задание 3. Оценка Data Encryption at Rest and In Transit

## Классификация данных и инструменты защиты

| Данные                                                                  | В чём необходимость защиты                                                                                                                                                    | Инструменты защиты                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Персональные данные (ПДн)(Ф.И.О., дата рождения, телефон, email, адрес) | Защита от утечки и несанкционированного доступа является прямым требованием законодательства РФ (ФЗ-152). Нарушение ведет к штрафам и репутационным потерям.                  | -Шифрование:При хранении (TDE в PostgreSQL) и при передаче (TLS).-Контроль доступа:RBAC/ABAC через IAM (Keycloak).-Аудит:Логирование всех действий через Audit Service.-Маскирование/Обфускация:Для тестовых сред.                                            |
| Медицинская информация(Диагнозы, анализы, заключения, история болезни)  | Это врачебная тайна, требующая наивысшего уровня конфиденциальности. Её раскрытие может нанести прямой вред пациенту и привести к судебным искам и отзыву лицензии у клиники. | -Шифрование:Обязательное шифрование на уровне базы данных и приложения.-Строгий контроль доступа:Только лечащий врач и пациент имеют доступ к полной информации. Для других ролей данные недоступны.-Data Lineage:Отслеживание всего жизненного цикла данных. |
| Финансовые данные(Платежи, контракты, начисления зарплат)               | Обеспечение коммерческой тайны и предотвращение финансовых махинаций. Целостность этих данных критична для ведения бизнеса.                                                   | -Контроль целостности:Использование транзакций в СУБД.-Аудит операций:Логирование всех финансовых транзакций в Audit Service.-Изоляция:Хранение в защищенной базе данных, доступ через специализированные сервисы.                                            |
| Данные для аналитики(Агрегированные и обезличенные данные)              | Защита коммерческой ценности аналитических выводов.                                                                                                                           | -Анонимизация/Псевдонимизация:С помощью Anonymization Service -Контроль доступа:RBAC-модель для аналитиков (доступ только к определенным срезам данных).-Аудит использования:Отслеживание, кто и какие отчеты строил.                                         |
| Логи и данные аудита (Действия пользователей, события безопасности)     | Эти данные являются доказательной базой при расследовании инцидентов. Их целостность и неизменяемость — ключевое требование для соответствия стандартам безопасности.         | -Изолированное хранилище:Отдельная Audit Database. -Неизменяемость (Immutability):Запрет на операции UPDATE и DELETE на уровне прав СУБД. -Мониторинг и SIEM:Автоматический анализ логов для выявления аномалий.                                              |

## Реестр программных и аппаратных средств для защиты данных

### Программные средства (Software)

| Категория               | Инструмент                             | Назначение                                                                                                                         |
| ----------------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Управление доступом     | Keycloak                               | Централизованная аутентификация и авторизация (IAM), Single Sign-On (SSO), управление ролями (RBAC).                               |
| Шлюз безопасности       | API Gateway(например, Kong, Traefik)   | Единая точка входа, TLS-терминация, проверка токенов, базовая защита от атак (WAF).                                                |
| Базы данных             | PostgreSQL                             | Основное хранилище с поддержкой шифрования (TDE) ClickHouseдля аналитики. Отдельная инсталляция PostgreSQL для логов аудита.       |
| Слой анонимизации       | Apache Airflow+Python-скрипты          | Оркестрация и выполнение процесса обезличивания данных.                                                                            |
| Аудит и мониторинг      | Audit Service                          | Сбор и запись логов. Victoria Metrics + Grafana для мониторинга. SIEM-система(например, ELK Stack) для анализа логов безопасности. |
| Защита от утечек        | DLP-система(Data Loss Prevention)      | Контроль за передачей данных во внешние каналы (почта, мессенджеры).                                                               |
| Безопасность разработки | SAST/DAST-сканеры(например, SonarQube) | Автоматический поиск уязвимостей в коде на этапе CI/CD.                                                                            |

### Аппаратные средства (Hardware) и сетевая инфраструктура

| Категория                | Компонент                              | Назначение                                                                                       |
| ------------------------ | -------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Сетевая безопасность     | Межсетевые экраны (Firewalls)          | Сегментация сети на зоны (Public, Application, Data Zone) и строгий контроль трафика между ними. |
|                          | Load Balancer (Балансировщик нагрузки) | Распределение трафика, защита от DDoS-атак, единая точка входа из интернета.                     |
| Серверная инфраструктура | Виртуальные или физические серверы     | Размещение контейнеров и баз данных.                                                             |
| Резервное копирование    | Система резервного копирования         | Регулярное создание зашифрованных резервных копий баз данных и конфигураций.                     |
